# DJI Raspberry Streamer

Ready-made SD-card image for the **Raspberry Pi 4B** that captures the live video of DJI
goggles and RC-N controllers and shows / streams it. Image releases only — no source code.

## Install

1. Download `orbit-rpi4-<version>.img.xz` from [Releases](../../releases).
2. Check it: `sha256sum -c SHA256SUMS` (optional).
3. Flash it to a micro-SD card (8 GB or more) with
   [Raspberry Pi Imager](https://www.raspberrypi.com/software/) ("Use custom") or
   [balenaEtcher](https://etcher.balena.io/). No need to unpack the `.xz`.
4. Put the card in the Pi 4B and power it on. Settings are in the web panel (see the
   QR code on the HDMI screen).
